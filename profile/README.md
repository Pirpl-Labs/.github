# Pirpl Labs

Practical security architecture, governance, and security program development.

Pirpl Labs helps small and mid-sized organizations build security programs that are proportionate to their risk, defensible in an audit, and realistic to operate.

Our work focuses on translating security standards and architecture principles into controls that can actually be implemented, measured, and maintained.

---

### Focus Areas

**Security Architecture**  
Zero Trust · Identity security · Cloud security · Technical control design

**Governance, Risk & Compliance**  
NIST CSF 2.0 · NIST SP 800-53 · GLBA Safeguards Rule · Risk management · Policy development · Audit readiness

**Security Operations**  
Detection engineering · Vulnerability management · Incident response · Asset management · Security program operations

---

### Approach

We favor practical, risk-based security over checkbox compliance.

Security controls should be implementable. Architecture should reflect real operational constraints. Governance should support decisions, not exist for paperwork alone.
